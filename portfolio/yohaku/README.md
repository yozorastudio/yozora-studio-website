# 余白 — yohaku

Yozora StudioのWeb制作営業用に作成した、架空のカフェ兼完全予約制エステサロンの自主制作デモです。実在店舗の受託実績ではありません。

## プレビュー・設置

`index.html`をブラウザで開くだけで閲覧できます。インターネット接続・ビルド・外部ライブラリは不要です。公開時はこのフォルダの全ファイルを同じ階層構成でサーバーにアップロードしてください。Yozora Studioの既存サイトのサブフォルダにも設置できます。

## ファイル

- index.html：ページ内容、メニュー、税込価格、店舗設定
- style.css：配色、レイアウト、スマートフォン対応
- script.js：モバイルナビゲーションと予約デモ案内
- assets/cafe.svg：このデモ用のオリジナルイラスト

## 実装内容

カフェ主体の1ページ構成／完全予約制サロン／開閉式FAQ／キーボード操作対応／動きを抑える設定への対応。予約ボタンは案内ダイアログを開きます。予約受付・フォーム送信・地図・アクセス解析は実装していません。

デモ表示はページ上部、店舗案内、フッター、予約案内にあります。検索エンジンにはnoindexを指定しています。ポートフォリオでは「自主制作・架空店舗デモ」と明記してください。

実店舗向けに転用する場合は、店名、料金、営業時間、所在地を確認し、予約ボタンを実際の予約サービスに接続してください。店舗写真に差し替える場合は利用許諾を確認してください。
