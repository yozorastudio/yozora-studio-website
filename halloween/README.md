# はじめてのハロウィン

GitHub Pagesの静的ページ。URL: https://yozorastudio.com/halloween/
既存の /style.css とロゴ・キャラクター画像を再利用し、追加CSSはこのページだけで読み込みます。既存ページ・共通スタイル・公開設定には変更を加えていません。

## 共通スマホ壁紙

assets/halloween-wallpaper.png はユーザー提供の元画像（1440 × 2559 px、5,221,249 bytes）です。リサイズ・加工はしていません。縦横比はほぼ9:16で、プレビューは全体が見えるように表示します。

halloween.js の wallpaper 設定に画像URLと保存ファイル名を指定しています。読込成功時だけダウンロードと拡大プレビューを表示し、失敗時は案内を表示します。JavaScript無効時にも直接画像を開くリンクとダウンロードリンクを用意しています。

壁紙差し替え時は assets/ 内の画像と wallpaper 設定を更新し、PC・スマホで実寸表示、プレビュー、ダウンロードを確認してください。OGPは既存 /ogp.png を使用しています。専用OGPが届いた場合は差し替え可能です。

## 4コマ・動画の追加

index.html の #comic と #video の Coming Soon を公開コンテンツに置き換えます。
4コマは画像・代替テキスト（必要なら台詞のテキスト）を、動画は確定した公式URLを設定してください。未公開リンクや空の埋め込みは設置していません。

## 公開前

- ブラウザで実表示・端末で画像保存を確認
- 必要なら配布条件を追記
- 必要に応じてトップページのWorksの導線と sitemap.xml にURLを追加
- ドラフトPRをレビュー後にマージ（自動公開は行わない）
