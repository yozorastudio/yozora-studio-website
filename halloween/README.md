# はじめてのハロウィン

GitHub Pagesの静的ページ。URL: https://yozorastudio.com/halloween/
既存の /style.css とロゴ・キャラクター画像を再利用し、追加CSSはこのページだけで読み込みます。既存ページ・共通スタイル・公開設定には変更を加えていません。

## 壁紙の公開（画像待ち）

1. ユーザーがリサイズした共通1種類の壁紙を受け取り、画像内容と縦横比を確認する（予定は9:16）。
2. このディレクトリに assets/ を作り、元画像を assets/halloween-wallpaper.png として追加する。JPEGの場合は実際の拡張子に合わせる。
3. halloween.js の wallpaper.src を "./assets/halloween-wallpaper.png" に設定し、filename も実ファイル形式に合わせる。
4. PC・スマホでプレビュー、保存、実画像のサイズ表示を確認する。画像が読み込めた時だけダウンロードとプレビューが有効になる。
5. 配布条件の文面はユーザーの方針を確認してから必要に応じて追記する。

画像未設定時は「準備中」を表示し、画像取得やダウンロードを行いません。画像読込失敗時にもダウンロードリンクを表示しません。JavaScript無効時は準備中と有効化の案内を表示します。
OGPは既存の /ogp.png を暫定使用します。専用OGPが届いた場合は差し替え可能です。

## 4コマ・動画の追加

index.html の #comic と #video の Coming Soon を公開コンテンツに置き換えます。
4コマは画像・代替テキスト（必要なら台詞のテキスト）を、動画は確定した公式URLを設定してください。
未公開のリンクや空の埋め込みは設置していません。

## 公開前

- 壁紙画像の追加と配布条件の確認
- 実画像で無料ダウンロード・プレビューを確認
- 必要に応じてトップページのWorksへ案内を追加し、sitemap.xmlにもURLを登録
- ドラフトPRをレビュー後にマージ（自動公開を行わない）
